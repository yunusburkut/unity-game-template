# __GAME__: asset sources

Where each shipped asset came from and what its licence lets the game do. One row per asset or folder that is not
ours or that an AI made; add the row in the same commit as the asset. `launch-review` reads this file before a store
submit: a row with an unknown licence blocks the upload, and the AI rows fill Steam's AI-content disclosure.

Author: a person, the vendor, or `AI: <tool / model>`. Attribution: `yes` puts the line on the credits screen.
